# Unglish review interface

The review page extends the existing demo's serif typography and grayscale light/dark palette. The displayed word is the primary visual element. Its size adapts to mobile screens and long spellings wrap without clipping.

Ratings use a vertical group of native radio controls with explicit labels and generous touch targets. Each word starts with no rating selected and the familiarity checkbox cleared. Selecting a rating never advances the task; a separate submit button does. A familiarity checkbox and skip button sit below the scale.

Use restrained borders, minimal containers, visible keyboard focus, and no decorative motion. Persistent status text distinguishes device storage from server acknowledgement. Pending submissions, errors, and final success are part of the primary flow, not transient notifications.
