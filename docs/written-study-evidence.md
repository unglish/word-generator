# Written comparison evidence

Q21 adds frozen baseline/candidate written comparisons, balanced blinded assignments, a durable local collector and a prospectively registered crossed reader/spelling analysis. The generator and original gate sources are unchanged relative to measured control `58baeaa388ee2d83e670764a94f649506b098464`.

Start with [the complete results and limitations](../evaluation/experiments/blinded-written-study/completed-evidence/RESULTS.md). The protocol and workflow are described in [written comparison](written-comparison.md), [collection and recovery](written-collection.md) and [inference assumptions](written-inference-method.md). Implementation entry points are the freeze/allocation/report modules under `evaluation/review/comparison/`; collector persistence and recovery live under its `collection/` directory.

All 14,400 registered synthetic datasets, 999 replicates each and 43,156,800 contrasts were independently reconstructed. Eleven specified calibration regimes pass; pooled observed coverage is 98.5%–99.833%, conservative under these laws. Informative candidate nonresponse retains only 28/1,200 full-truth covers and mean bias −0.1946573. It supplies no correction for informative human attrition. Benefit/harm detection is reported without adding a retrospective power gate.

All 28 original baseline/candidate commands completed: 26 passed and two lint runs failed with the same 11 inherited errors. Unit tests, compiler, quality, trigram/trace diagnostics, review checks and all 12 native performance runs passed. The median candidate/control throughput ratio is 0.992709 from the original rounded logs; this is not an output-quality gain. Original sample sizes, timeouts and floors remain unchanged. The earlier dependency-recorder failure and dormant scheduling supersession remain in the evidence.

The public packet verifies every compact artifact and independently recounts all 36 calibration contexts. Six altered complete packages were rejected, including missing original data, falsified native outcomes, false informative-loss success and a credential-value injection. Run `python3 verify.py --root .` inside `evaluation/experiments/blinded-written-study/completed-evidence` to recheck it. The supplemental `publication-proof-index.json` binds the final operators and verdict logs; retained local indexes expose every original path and hash.

All 30,263 original archive files and 7,676 additional gate-provenance entries were rehashed on the evidence owner's machine. `--full-local` repeats original/retained raw, source and installed-runtime checks there. Four fixture credential files retain original bytes only in the verified local archive; public evidence includes hashes and scans all decoded artifacts against all 27 authentication-value hashes. Filesystem clones have independent inodes and share extents; this is local retention, not an independent-device backup.

The PR uses the preserved exact control branch `depatched/written-study-control-58baeaa`; the current baseline PR has advanced beyond the measured control. No actual readers, piloted stopping rule, verified identity/attention, observed preference or generated-quality improvement are established. Study infrastructure and bounded synthetic calibration do not complete the actual human-study requirement or establish merge readiness.
