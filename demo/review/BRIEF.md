# Written plausibility review

Mode: Operate.

Audience: anonymous readers comfortable with English, using desktop or mobile web. Task: judge 20 distinct spellings one at a time with the agreed written-v1 rubric, familiarity checkbox, and skip option.

The word leads; scale labels remain fully visible. No pronunciation, diagnostics, generation metadata, results, account controls, or reviewer history appear. The existing demo's visual identity is authoritative. Implement directly in HTML/CSS/TypeScript; no raster assets are needed.

The flow is introduction → active review → pending delivery, if needed → confirmed completion. Durable storage failure pauses advancement. Keyboard and narrow-screen usability are required. Success is confirmed delivery of every response, not merely reaching the last word.

The current rubric asks “How much does this look like an English word?” with Not at all / A little / Moderately / Very much / Completely. A short first-impression instruction and optional per-word comment field support the judgment; comments remain private and are capped at 2,000 characters. Unfinished v1 sessions retain their original wording and no comment prompt.
