# Q13c current analyzer boundary (before formal capture)

This is a separately named analyzer. The historical `analyze.ts`, observer,
registration, protocol and archived fixtures remain unchanged.

`analyze-current.mjs freeze OUT` records all source and quality code/JSON files,
package and compiler inputs, this contract, the actual effective English config,
Node executable and the ten registered historical preparation artifacts. Output
must be outside the source checkout. A freeze made by a synthetic test is not the
reviewed experiment freeze. Final source review and fixture completion precede a
formal freeze; no candidate capture has been performed with this analyzer.

`analyze FREEZE FREEZE_SHA RUN MANIFEST_SHA OUT` requires externally reviewed
SHA-256 values for both the source freeze and the input manifest. It verifies the
original fixed development protocol, common evaluator/reference identities,
archived source bundles, effective configuration, exact artifact and scheduled
shard sets, complete ordered coordinates, and all input hashes before and after
processing. Missing, extra, aliased or changed inputs fail without publishing a
success report. Output creation is exclusive and protects source/archive trees
through resolved aliases. The freeze and manifest must be retained separately;
self-consistently replacing both data and its claimed hash is not authenticity.

The same current observer explicitly dispatches historical v1/v2 and current v3
ledgers. It reports counts at total, profile, stream and actual resolved
morphology strata, preserving planned-only labels when historical evidence lacks
resolved forms. Event/unit counts and any-event word incidence stay distinct.
Replay summaries report zero certificates as not applicable, with a null fraction;
missing historical observations remain unavailable. This analyzer does not
interpret either state as a successful replay fraction.

V3 license checks use the production verifier. They are not an independent raw
structural recount, a re-execution of generic spelling regexes, or a human
wordlikeness judgment. The separate independent recount and formal compatibility
study remain required. This report does not waive existing quality/performance
gates or replace common baseline/previous/candidate distribution comparisons.

Synthetic tests exercise file/ancestor aliases, publication overlap, occupied
outputs, artifact sets, byte corruption, duplicate pins, shard schedules, malformed
compressed rows and changed source freezes. They intentionally do not simulate a
200,000-word result or claim full-corpus success.
