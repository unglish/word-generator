# Completion vowel support experiment

The frozen Q14a development corpus contains 2,855 infeasible completion attempts. Full trace accounting attributes 2,624 to an initial `/eɪ/` pool containing only open-vowel `a` and lexical-only `ae`. Another 231 attempts fail projected reading or ownership checks.

This experiment adds `splitVowels.completionWeights`, a list of structured inventory identities (`phoneme`, `form`) and positional weights. Completion can give `ai` initial-syllable weight 2, using its existing medial weight, while retaining frequency, stress modifiers, contextual restrictions and reading metadata. Initial spelling selection uses the original configuration. The option is absent by default.

Each identity must match exactly one inventory entry and occur only once. Supplied weights must be finite and nonnegative. The implementation clones the existing configuration object graph, preserving map membership, cumulative frequencies and cloned inventory identity without mutating the caller's inventory. Unsupported readings, fallback-only eligibility and projected neighboring readings retain their checks. Attempts remain subject to weight reconstruction and transaction verification.

The registration precedes runtime changes. The full 200,000-word capture and production semantic verifier are complete. Support-only infeasible attempts decrease from 2,624 to zero; total infeasible attempts decrease from 2,855 to 239. Final unresolved root obligations decrease from 2,887 to 277, while unavailable root statuses change from 8,051 to 8,026. These are aggregate stream comparisons; the added completion draws can change subsequent RNG consumption. The unchanged-option public compatibility workload passes all 83,072 calls. The default suite has 1,028 passing tests, four original assertion failures and one skip, with no timeouts. The unchanged opt-in quality workload has ten passing tests and two failed gates: five-consonant runs remain 82, while owngs rises from 61 to 63. The full 50,000-word trace audit has mixed results, all retained. The independent full-corpus recount passes 3,800,019 integer comparisons across all 200,000 words and confirms the reported root and completion counts. It independently checks counts and structure; production verification authenticates reading licenses. The complete isolated twelve-slot timing series measures a -4.98% median paired throughput change (all six pairs adverse, ranging from -6.41% to -4.07%). Both arms fail all six speed-floor gates and pass all six variance gates. The spelling-support gain therefore comes with a measured performance regression. Passing focused tests is not output-quality acceptance. Ownership loss and other reading failures remain part of Q14a's original zero-unresolved target.
