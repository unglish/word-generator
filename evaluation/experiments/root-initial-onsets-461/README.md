# Polysyllabic root onsets (#461)

Baseline: `7edba6d00a6d07ba2994187289fadd47c2c40ef1`. The parent of this evidence commit is the implementation tested.

The two 20,000-word lexicon runs use default morphology, seeds 20261124 and 26410157, and public generation with traces. The comparison counts realized onset lengths on lexical roots. The medial report also includes the intervocalic consonant count, which does not require inferring the syllable split. The spelling pileup report gives the fixed 100,000-seed test and a separate uninterrupted 60,000-word stream.

The blind sample uses seed 3170419623, bare lexicon roots and trace-enabled replay from each draw's RNG position. Each retained pair has the same root syllable count and target phone count. Updated roots have two initial consonant phones. The gained group has zero or one before, and the shared group has two before. There are 1,000 pairs in each group and 2,000 distinct updated spellings. Candidate sides were independently shuffled and balanced within each group. Three model raters judged spelling before opening the separate IPA input. Each pair had one judgment per pass. Pronunciation was judged from IPA. The results file contains all votes attributed to the appropriate version, and the key records the displayed side.

The three raters favored the first display position overall. The gained group favored the update on both passes even in the 500 pairs where it appeared second. Selection conditions the results on the updated root having a two-phone onset. A prior unfiltered 80-pair review was mixed.

The full local check passed 1,303 core and quality tests and 313 review tests. The Python stage-reference suite passed 8 tests, and the pinned artifacts regenerated byte-for-byte.
