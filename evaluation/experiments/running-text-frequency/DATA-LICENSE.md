The SUBTLEX-US frequency and POS source is credited to Marc Brysbaert, Boris New and Emmanuel Keuleers. Source documentation: https://www.ugent.be/plone_portal/pp/experimentele-psychologie/en/research/documents/subtlexus/overview.htm. The registered POS workbook URL is https://osf.io/download/7wx25/.

The captured official source notice states CC BY-NC-SA 4.0. Preserve attribution, noncommercial use and share-alike terms for the SUBTLEX-derived research data, including the fitted frequency/count artifact and its derived target tables; these are separate from the repository's MIT code. The archived source notice appears in `evidence/licenses/SUBTLEX-US.txt`; the terms are available at https://creativecommons.org/licenses/by-nc-sa/4.0/.

CMU citation pronunciations use cmusphinx/cmudict revision `74790861f652b15e4ac49015a90074ad62a27690`. The retained Carnegie Mellon University copyright, redistribution conditions and disclaimer are in `evidence/licenses/CMUdict.txt`, fetched from https://raw.githubusercontent.com/cmusphinx/cmudict/74790861f652b15e4ac49015a90074ad62a27690/LICENSE. The source SHA-256 and pronunciation selection are registered separately.

Combined derived research artifacts retain both source notices. Generic parsing, modeling, diagnostics and API code remain separately licensed as code; this experiment does not promote externally supplied data into default runtime tables. Raw source downloads and large output archives are retained locally and identified by the published index rather than silently relicensed or included as unmarked code assets.
