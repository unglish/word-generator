# Completion verification experiment

The original ledger authenticates a selected completion attempt, then transaction preparation authenticates that same attempt again before allocation. The candidate authenticates selected attempts through transaction preparation and authenticates all other attempts directly. Every path still validates before changing cells, IDs, certificates, attempts or timeline entries.

The registration precedes runtime changes. Fourteen focused tests pass, including stale selected evidence and forged nonselected evidence rejected before mutation. TypeScript and changed-source lint pass. A full public capture reproduces all 200,000 original opt-in Word/WordTrace records and all twenty compressed shard hashes exactly.

The omitted-option public compatibility workload passes all 83,072 calls across 20,768 coordinates and 128 next-RNG probes. The full default suite has 1,022 passing tests, four original assertion failures and one skip, with no timeouts. The unchanged 50,000-word opt-in quality workload has ten passing tests and two original failed gates; its complete metrics report is byte-identical to the original report (82 five-consonant runs and 61 owngs occurrences). The original 50,000-word seed42 trace audit produces byte-identical complete reports in both arms, covering trigrams, hiatus, glide, morphology and structural metrics. This audit defines no default failure thresholds. The complete isolated twelve-slot series measures a median paired throughput change of +3.65%; individual pairs range from -1.30% to +4.65%. All six variance gates pass per arm, while all six speed-floor gates fail per arm. This single registered series establishes the observed effect for this environment, not a universal speedup. The performance comparison uses the same original opt-in configuration in both arms and the original benchmark workload, seeds, thresholds and twelve-slot order. Both gate failures and timing variance will be retained. The measured throughput change preserves the failed speed-floor gates and establishes no output-quality improvement.
