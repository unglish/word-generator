# Q09 runtime archived-word supplement v1

This supplement fills broader endpoints already named in the frozen runtime
`design-v1.md` and `observer-contract-v1.md`. It does not change the generator,
capture, accepted pure law, penalty, quality gates, or existing reports. No
archive analysis is authorized by preparing these files. Parent source review
and an externally supplied SHA-256 of the authority specification precede any
formal execution. All implementation, test, contract, and runner bytes are
listed explicitly in that specification, along with the original capture freeze,
both raw archive manifests, both observation reports, and independent proof.

## Availability and domains

Observe each recorded actual domain separately. The common endpoint
`root-placement-complete` aliases v1 `root-after-rhythmic` and v2
`root-after-pattern-application`. An absent snapshot receives availability
`unavailable-historical`, except a phase replaced by the other schema receives
`not-executed`. Missing data has no numeric endpoint fields and never receives
zero-defect credit. Unsupported trace versions fail rather than becoming absent.
The detached proposal is a separate active-only mechanism endpoint, not an
actual historical snapshot. Zero-syllable affixes retain their morphological
identity, but do not create invented syllable boundaries.

For every observed domain count marked adjacency orientation (P-P, P-S, S-P,
S-S), exact assignment-origin pairs, and the explicit root/prefix/suffix
coordinate boundary. Count maximal unmarked runs by initial/internal/final/
whole-word position and exact length, plus the already specified >=2 and >=3
endpoints. Word-with counts and run counts are separate. Keep primary/secondary
counts, missing/multiple primary word counts, exact secondary positions, and
secondary schwa counts and eligible secondary-syllable denominators.

Weight observations recomputed from a domain's saved phones use the pinned
quantity policy and are explicitly `descriptiveSnapshotWeight`; they are not
claims that the runtime reweighed that domain. Runtime placement coverage uses
the fixed before-primary operational-heavy vector. Heavy-secondary coverage
has heavy nonprimary syllables as denominator because primary positions cannot
be selected secondary. A zero denominator yields no coverage ratio. Quantity
unknown/mismatched/legacy-policy observations remain explicit even when codas
provide an operational heavy classification.

## Returned-attempt mechanism and strata

Actual retained proposal and application patterns supply K, adjacency, and the
full signed application-minus-proposal adjacency distribution. Report both
patterns' full adjacency/excess-above-positive-support-minimum distributions,
and their pattern-feature differences. Positive-support minimum comes from the
independent literal-history law, never the observed sample or an epsilon cutoff.
The saved `trace.attempts` is the zero-based selected attempt index. It does not
count all attempts executed, establish acceptance probability, or reconstruct
discarded histories.

Aggregate total, profile, profile/stream, and profile/actual-morphology/root-
length/final-length groups, plus named profile/root-length/K/primary-position/
operational-heavy-mask/quantity-unknown-mask groups. The primary-position label
retains the exact index and edge/interior class. K for common root placement is
observed separately in each variant; conditional-law inference is active-only.
All availability denominators reconcile per group. Counts are integer counts;
ratios retain explicit numerator and denominator.

## Continuous-law reference expectations

For every active actual input/K context, enumerate the frozen independent
literal histories, preserve duplicate histories' mass, and include all same-
primary/K patterns, including exact zeros. Original expectations are Fractions;
tilted expectations use Decimal exponentiation of the exact binary64 lambda,
checked at 100 and 140 decimal digits. Report adjacency, run counts/word-with
counts, position and edge/interior secondary counts, and operational-heavy
secondary coverage. Retain exact rational original values and decimal strings.
Compare existing production mass claims only at their already registered
tolerances. No new outcome threshold is added.

Per-context mathematical values are primary. Any aggregated reference weights
contexts by their explicitly reported retained-use counts and is labelled
`retained-context-standardized continuous-law expectation`. Neither these
expectations nor retained frequencies are a new finite-machine sampler proof,
unbiased pre-rejection frequency estimate, paired control/active word experiment,
or perceptual-quality proof.

## Deterministic bounded witnesses

Traverse the frozen profile/seed/draw schedule. Retain the first full archived
word (one per condition per named group) for these fixed conditions: observed
adjacency increase; >=2-run or >=3-run increase; heavy-secondary coverage loss;
secondary-stressed schwa; traced `repairStressedNuclei`; positive selected attempt
index; variable positive-support adjacency cost; changed proposal/application
pattern; and applied excess above the support minimum. Retain coordinate,
word SHA-256, complete archived word, context id where available, and the exact
condition evidence. Witnesses are not severity-ranked or chosen by inspection.
Failures preserve a fresh failed report and the offending coordinate; do not
discard or silently continue past a failed record.

## Authority and execution

The external specification binds complete own source paths, original source
freeze and all its source/dependency/reference groups, embedded archived source,
exact schedule/shard/filesystem sets, all artifact sizes and hashes, generator
config/producer/engine identities, prior reports, and independent proof. Check
before and after reading. Consume each scheduled record once in order; verify
coordinates, counts, retained RNG accounting and report context use. Reject
symlinks, duplicate/unlisted artifacts, malformed integer coordinates, source
changes, report changes, and existing/overlapping output destinations.
Only after all checks finish may an exclusive result be marked passed.
Supplement modules are compiled directly from the pinned source bytes, bypassing
unlisted bytecode caches. Optimized Python is rejected in the reserved-output
handler. After the authority helper bootstraps, constructor/validation/analysis
failures retain an exclusive failed report; interpreter or helper bootstrap
failures remain process failures to preserve in the execution log.

Tests use hand-built synthetic words, laws, and tiny archives; they do not call
the generator and cannot inspect or tune to the formal archived corpus.
