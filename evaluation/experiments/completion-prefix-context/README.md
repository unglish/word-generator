# Completion prefix context experiment

See registration.json for the prospective scope and RESULTS.md for measured outcomes and failed gates. Evidence is indexed by SHA-256 and byte length in evidence/index.json. Same-device retention is not an independent backup.

Run `python3 evaluation/experiments/completion-prefix-context/verify.py` to authenticate every packaged artifact. This verifies packaging integrity, not linguistic correctness or human outcomes.
