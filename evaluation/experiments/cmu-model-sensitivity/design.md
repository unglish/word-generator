## Recommended single PR

Add an offline, source-frozen comparison of the **same ordered English and saved generated phone vectors** under two explicitly identified count tables, with the existing scoring formula held fixed. Its output is a measurement-sensitivity artifact, not a replacement baseline, public scorer, threshold, or generator configuration.

A new builder is no longer the missing piece. #325 already compares six marginal references against the same original 200,000 words (`evaluation/corpus/sensitivity.ts:31`): letters, internal bigrams/trigrams, written length, syllable count, and projected phone frequency. Its complete artifact and result remain authoritative for that question. #332 supplies the previously missing native/base phone-transition tables; #333 supplies exact ordered English inputs and old-model scores. Neither changes a live consumer. This PR fills the remaining **model/count-table sensitivity** gap and inventories consumers for subsequent independent adoption decisions.

The hypothesis is reproducibility/accounting: changing only the count table can move a measured score and its English/generated gap even though no generated word changes. There is no hypothesis that the new scores must rise or that readers prefer the output. No positive result is required for acceptance.

## Fixed scoring experiment

A = exact historical table; B = #332 `artifact.transitions.base`. Require the same 40-symbol vocabulary (including `#`) and validate every row total and all counts. A has 1,338 observed bins and 976,831 events; B has 1,339 observed bins and 859,818 events. Do not rescale counts, tune alpha, restrict vocabulary to observed corpus tokens, or switch to the 70-symbol native-stress table.

For each input of n phones, form `# p1 ... pn #`. Compute the sum in transition order of `log2((count(first,second)+1)/(rowTotal(first)+40))`; divide by n+1 for the per-transition score. Preserve legacy independent value sorting before sequential mean accumulation, upper-middle median, and finite/all-row policy for this known complete population. Add explicitly labeled min/max and a preregistered quantile convention only if needed, never replace historical aggregation. The legacy scorer is a transition-score comparator, not a pronunciation acceptability oracle.

Use a small typed pure offline evaluator receiving a validated immutable table. It is not an overload/change to `src/phonotactic/score.ts`, not a public runtime API and not a generalized model registry. Model A must match the actual unchanged scorer on every scoreable English and generated vector. On English rows it must additionally match every #333 ordered score and aggregate. No new-model result is an excuse to loosen A parity.

Primary descriptive outputs, fixed before scoring:

1. Full ordered input identity, projection/availability, A/B total and per-transition score, and B−A deltas for every row. English source line/ordinal/spelling and generated profile/seed/draw index remain distinct identity types. Save compressed row streams rather than summary-only evidence.
2. All-row/scoreable/unavailable denominators; counts by reason and overlapping loss masks, with exhaustive partition counters kept separate from overlapping counts.
3. Paired score summaries and delta mean/min/max/upper-middle median; positive/zero/negative counts by exact JS arithmetic, with a separately labeled near-zero tolerance count. Independent numeric acceptance tolerance must not redefine the scientific sign categories. Near-zero disagreements are reported rather than silently forced to zero.
4. Totals, each of four generated profiles, each of 20 streams, and exact original phone-count strata. Identity-complete subset uses the same grouping and fixed vector; no newly selected favorable cohort or resampling. Every stratum partitions its parent exactly; empty comparisons are unavailable, never mean zero.
5. Transition-level observed counts in each input population, old/new raw counts and row denominators, seen/unseen status under both models, and old/new log probabilities. Attribute delta to the actual numerator and row-denominator changes. Weight the contribution by observed multiplicity and reconcile against summed word scores within the frozen numeric tolerance. Word-normalized means and pooled transition-normalized scores are different; the latter, if included, must have an explicit separate label.
6. English mean E_A/E_B on the same117485 rows and each generated G_A/G_B. Gap sensitivity is `(E_B−G_B)−(E_A−G_A) = (E_B−E_A)−(G_B−G_A)`, with all units/cohorts stated. No mixed-model `E_A−G_B` is treated as quality. The old rounded123892 summary is not a fifth scoring cell or a gate target.
7. Deterministic diagnostic witnesses: first ordinal for each changed support category and each missing/ambiguous mapping category, plus maximum-absolute per-word delta with first-coordinate tie breaking. Attach corresponding original trace identity, actual sounds and model contribution records; extremes are diagnostic, not representative human samples.

All selected English transitions are training events for B. B's English score is in-sample; A's source overlap is historically unresolved but substantial overlap is plausible, not quantified. Model comparison cannot distinguish source revision, exclusion policy, count magnitude or effective smoothing changes inside the historical table. Keeping alpha=1 does not hold the effective regularization mass fixed when row totals change. These are documented properties of a **count-table sensitivity** experiment, not evidence that one model predicts held-out English better. Bare roots and forced monosyllables are not matched whole-dictionary stem populations. No familiarity/POS/token frequency or held-out human preference is invented.
